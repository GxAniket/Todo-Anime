## 📦 Overview

**Todo** is a modern productivity application designed to help users organize their daily tasks, manage priorities, plan their schedules, and maintain a focused workflow.

The application provides a clean and responsive interface with dedicated views for daily, weekly, monthly, and study planning.

---

## ✨ Features

- 📝 **Create Tasks** — Add tasks with name, date, time, and priority
- ✅ **Complete Tasks** — Mark tasks as completed
- ✏️ **Edit Tasks** — Update existing tasks
- 🗑️ **Delete Tasks** — Move unwanted tasks to Trash
- ⭐ **Priority Management** — Organize tasks by Low, Medium, and High priority
- 📅 **Today View** — Focus on tasks scheduled for today
- 📆 **Week View** — Plan tasks across the week
- 🗓️ **Month View** — View and organize tasks throughout the month
- 📚 **Study Planner** — Manage chapters and study goals
- ⏱️ **Pomodoro Timer** — Focus using customizable study sessions
- 🌙 **Dark Mode** — Modern dark interface
- ☀️ **Light Mode** — Clean light interface
- 📱 **Responsive Design** — Works across desktop, tablet, and mobile screens
- ⚡ **Fast & Lightweight** — Built with React.js and Vite

## 🎯 Project Goals

The main goal of **Todo** is to build a practical and modern productivity application while improving frontend development and UI/UX skills.
